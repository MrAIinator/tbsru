# TBS Russian

Подмод перевода **The Broken Script** на русский. Это не перезалив мода и не его ресурсы.

Русский появляется только если выполнены оба условия:

1. Рядом установлен официальный The Broken Script `2.x` для NeoForge 1.21.1.
2. В игре выбран язык **Русский**.

Без этого подмода игра остаётся английской. Файл `en_us` основного мода не подменяется.

## Что переведено

- Предметы, блоки, чат мода, смерти, интерфейс, настройки, субтитры речей.
- Фразы, которые нужно написать в чат, можно писать по-русски. Имена персонажей остаются как в моде: `null`, Herobrine, Circuit, Integrity.
- Надписи на табличках структур переводятся построчно, короткими фразами, чтобы читались вместе. Имена игроков и глитч-шифры не трогаются.
- Индексы библиотеки «Арки пряжи», книги 1–45, показываются по-русски, только если язык игры русский. Слова анимаций, которые рисуются поверх абзаца (`lungs`, `heart`), больше не подменяются длинным текстом и не наезжают на строку.

Официальный jar The Broken Script сюда не входит. Его лицензия это запрещает.
